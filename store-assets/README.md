# Chrome Web Store Assets

Generated assets for the Chrome Web Store listing.

- `ld-friends-icon.svg`: source for the extension/store icon.
- `ld-friends-icon-128.png`: 128x128 store icon.
- `small-promo-tile.svg`: source for the 440x280 small promo tile.
- `small-promo-tile-440x280.png`: Chrome Web Store small promo tile.

Design notes:

- The mark uses a black, white, and orange badge with peeking eyes to suggest quietly watching followed linux.do activity.
- The layout borrows broad forum-color cues without copying the official linux.do logo.
- The promo tile avoids privacy overclaims and keeps marketing text minimal.
