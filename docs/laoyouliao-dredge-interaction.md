# 佬有料与打捞交互约定

更新时间：2026-07-01

## 目标

这份文档固定 `佬友圈`、`佬有料`、`自动捞料` 三个概念的产品边界，避免后续把“浏览公开动态”“规则收录结果”和“定时执行状态”混在一起。

## 心智模型

### 佬友圈

`佬友圈` 是日常浏览入口。它展示公开动态，用户可以按用户和类型筛选，并通过 `刷新动态` 手动刷新当前筛选范围。

关键约定：

- `刷新动态` 只按当前 `佬友圈` 筛选刷新。
- `刷新动态` 不再提供下拉菜单。
- `佬友圈` 不承载打捞规则设置入口。

### 佬有料

`佬有料` 是本地收录列表。它展示被打捞规则命中的公开动态，类似一个由规则筛出来的本地收件箱。

关键约定：

- 初始可以为空。
- 空态文案需要引导用户去设置页新建打捞规则，然后手动刷新佬友圈或开启自动捞料。
- 顶部需要有独立的 `立即打捞` 主按钮。
- `立即打捞` 使用自动捞料/打捞规则对应的范围，不读取当前 `佬友圈` 筛选。
- 规则管理入口使用短文案，例如 `配置打捞规则`。

### 自动捞料

`自动捞料` 是定时执行状态和控制，不是内容发现入口本身。

关键约定：

- 胶囊本体表达开启/关闭、等待下一次、倒计时、运行中等调度状态。
- 胶囊本体使用 `Telescope` 表达打捞行为；真实请求运行中切换为转圈图标。
- 等待态文案使用 `下次打捞 HH:MM:SS`，不常驻 `自动捞料` 前缀。
- 下拉菜单可以包含启停、低层级 `立即打捞`、`配置打捞规则`。
- 开启态在下拉中用勾选样式表达。
- 下拉分割线需要清楚，且不能在窄屏被右侧或底部裁切。
- 自动捞料依赖插件界面打开，界面需要提示 `保持插件界面打开，自动捞料才会运行。`
- 运行中的自动捞料被关闭时，立即释放自动捞料对调度和刷新按钮的占用。
- 首版关闭语义是软退役，不强行中断已经发出的 linux.do 请求；旧请求自然返回后不能继续下一段打捞，也不能重新锁住刷新按钮。

### 打捞起点

`打捞起点` 是整个打捞规则集的开始时间，用来避免首次打捞把历史命中全部收进 `佬有料`。

关键约定：

- 界面使用 `打捞起点`，不使用 `水位线` 文案。
- 整个规则集只有一个打捞起点，不做每条规则独立起点。
- 语义规则变更会重设整个 `佬有料` 的打捞起点，这是有意的粗粒度模型。
- 新建、删除、修改规则范围、修改关键词、启用或停用规则，都会把打捞起点重设为当前时间。
- 修改规则名称可以不重设打捞起点。
- 开启或关闭自动捞料不重设打捞起点。
- 自动捞料开启时，规则区只读；关闭自动捞料后才能修改规则。
- 收录时只收集发生时间晚于打捞起点且命中规则的公开动态。
- 用户可以 `重设为现在`，但不支持选择过去时间或历史补录。

## 图标语义

`Telescope` 用于“发现/打捞/佬有料/打捞规则/立即打捞/自动捞料等待态”这一组语义。

应该使用 `Telescope` 的位置：

- 插件页 `佬有料` 标题或入口。
- 插件页 `立即打捞` 按钮。
- 设置页 `佬有料` / `打捞规则` 标题或入口。
- `自动捞料` 胶囊的非运行态。
- 自动捞料下拉里的低层级 `立即打捞` 菜单项。

不应该使用 `Telescope` 的位置：

- `自动捞料` 真实请求运行中，此时使用转圈图标。
- `佬友圈` 的普通 `刷新动态` 按钮。

## 刷新语义

| 入口 | 刷新范围 | 是否下拉 | 说明 |
| --- | --- | --- | --- |
| `佬友圈` / `刷新动态` | 当前用户筛选 + 当前类型筛选 | 否 | 用于浏览当前视图 |
| `佬有料` / `立即打捞` | 打捞规则反推范围 | 否 | 用于主动收录命中规则的公开动态 |
| `自动捞料` 下拉 / `立即打捞` | 打捞规则反推范围 | 是 | 低层级辅助入口 |
| `自动捞料` 定时执行 | 打捞规则反推范围 | 不适用 | 侧栏打开时运行 |

## 安全边界

本功能不改变既有请求和安全边界：

- 不新增 linux.do 请求路径。
- 不绕过 Cloudflare。
- 不导出或重放 Cookie。
- 不新增 proxy、DNR、webRequest 或远程代请求。
- 不把侧栏打开时运行的定时刷新改成真正 headless 后台刷新。

## 验收要点

- 插件页和设置页的 `佬有料` / `打捞规则` / `立即打捞` 能看到 `Telescope`。
- `自动捞料` 胶囊非运行态使用 `Telescope`，运行中使用转圈图标。
- `自动捞料` 等待态显示 `下次打捞 HH:MM:SS`。
- `佬有料` 有独立 `立即打捞` 主按钮。
- `佬友圈` 的 `刷新动态` 是单按钮，没有右侧下拉。
- 自动捞料下拉启用态是勾选样式，分割线清楚，窄屏不裁切。
- 设置页展示 `打捞起点`，不出现 `水位线` 文案。
- 自动捞料开启时，打捞规则区只读。
- 对应 UI、静态 CSS 和请求语义测试需要覆盖。
